Natural Language Processing: English-to-Sindhi Translation
Team Members: Misbah Ibrahim, Neha Aamir Topic: Machine Translation for Indic Languages

Project Summary
This folder contains the complete workspace for our NLP semester project. The primary goal of this study is to implement and evaluate a translation model converting English text into Sindhi using the enclosed parallel corpus.
